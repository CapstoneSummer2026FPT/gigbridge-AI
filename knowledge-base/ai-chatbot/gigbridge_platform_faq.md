# GigBridge Platform Overview

GigBridge is an advanced microservice-driven platform designed to connect corporate clients with independent freelancers, gig workers, and contractors. 

## Key Features

1. **Job Creation**: Clients can quickly post job listings, which are refined and enhanced using AI (NLP tools).
2. **AI-Driven Screening**: Candidates undergo interactive screening sessions, simulated by our AI Interview system. This system evaluates their answers using LLM logic, and also supports voice-based speech recognition (STT) and voice replies (TTS).
3. **Smart Matching**: The platform features automated candidate-to-job matching, which queries candidates' profiles via vector search and generates recommendations.
4. **AI-Assisted Dispute Audit**: In case of project disputes or milestones discrepancies, the AI system audits communication transcripts and provides risk indicators (Low, Medium, High) alongside recommendations.
