# Manage Job Screening Questions

**Route:** `/client/job-posts/:jobPostId/questions`

**Access:** Clients with a completed profile who can manage the job.

Clients use this page to review and maintain the interview or screening questions associated with a project request. Questions can be added, edited, removed, reordered, and marked as requiring an answer or allowing an optional response.

These questions are used during the freelancer application and, when configured for the supported AI interview flow, can provide the question set for that interview. Changes must pass validation and be saved before applicants receive the updated set.
