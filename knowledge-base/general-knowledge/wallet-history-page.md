# Wallet History

**Route:** `/wallet/history`

**Access:** Signed-in users with completed setup.

Wallet History lists recent wallet transactions and displays cumulative summary values for deposits, holds, refunds, withdrawals, and transaction counts. Summary cards are based on the full account history when the summary API is available.

Users can search the ledger and filter by transaction type and status. Opening a row shows the transaction detail available from the backend. Pending PayOS top-ups are synchronized so their displayed status can advance to succeeded or cancelled.
