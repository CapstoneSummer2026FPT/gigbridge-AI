# Project Workspace

**Route:** `/workspace/:contractId`

**Access:** Authorized participants in the contract.

The workspace is the shared execution area for a contract-backed project. It brings together the contract and milestone context with the collaboration information implemented for that project, such as work/task progress and participant activity.

Participants can review current project state and use the available role-specific actions. The workspace also connects to the contract reporting/dispute flow so issues can reference the correct contract context.

Workspace access is tied to the contract ID and participant authorization; it is not a public project page.
