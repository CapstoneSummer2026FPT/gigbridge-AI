# Approve Milestone

**Route:** `/contracts/:contractId/milestones/:milestoneId/approve`

**Access:** The client participant for an eligible milestone.

The page lets the client review the milestone's agreed scope, acceptance criteria, submitted deliverables, and current state before deciding on the available action.

Approval is a financial action because it can trigger the platform's escrow release flow. The page requires current, eligible milestone data and confirms the server result. If the work is not acceptable, the client uses the supported revision/report process instead of approving it.
