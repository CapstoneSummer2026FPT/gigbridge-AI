# Financial Overview

**Route:** `/financial-overview`

**Access:** Signed-in users with completed setup.

The Financial Overview uses account and role data to summarize client payments or freelancer earnings. Users can select a supported reporting period and review total/average amounts, progress against contract value, service fees, trend charts, and recent transactions.

Amounts are displayed in GigCoin. Transaction timestamps use Vietnam time where formatted by the page. The current view can be exported as CSV for offline analysis.
