# Job Post Review

**Route:** `/jobs/post/review`

**Access:** Clients with a completed profile and job-draft state.

The review page presents the job information collected during the creation flow so the client can verify the request before publishing. It is intended to catch missing or incorrect title, scope, taxonomy, skills, budget, schedule, interview questions, or milestone information.

The client can return to earlier steps to edit the draft. Publication is only attempted after the current draft passes validation; a failed request remains available for correction or retry.
