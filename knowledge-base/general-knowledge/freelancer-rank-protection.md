# Freelancer Vacation Mode and Rank Protection

**Route:** `/premium/freelancer/rank-protection`

**Access:** Freelancers with active Premium access.

Vacation Mode lets a Premium freelancer select an end date, optionally record a reason, and request rank protection for the configured period. The end date cannot extend beyond the active Premium coverage shown by the page.

An active protection period displays its end date and can be ended early through a confirmation action. All changes must be accepted by the backend before the displayed status changes.
