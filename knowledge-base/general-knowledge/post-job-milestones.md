# Job Milestone Setup

**Route:** `/jobs/post/plan`

**Access:** Clients with a completed profile and an in-progress job draft.

Clients can define a baseline payment plan before publishing. Each milestone can describe a measurable phase, amount, duration or deadline, scope, deliverables, acceptance criteria, and smaller work-breakdown tasks.

Milestone amounts determine the planned fixed project budget. Publishing the project request does **not** fund escrow; funding occurs later in the contract workflow. The freelancer may propose a more detailed task breakdown when applying.

The client may return to job details or publish the project request when validation succeeds.
