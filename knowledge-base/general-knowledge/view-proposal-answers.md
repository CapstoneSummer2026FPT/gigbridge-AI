# View Proposal Answers

**Route:** `/proposals/:proposalId/answers`

**Access:** Signed-in participants allowed to view the proposal.

The page displays the job screening questions and the answers submitted with the selected proposal. It is a review screen rather than the application editor.

Required/optional context and unanswered optional questions are shown according to the stored proposal data. If the proposal cannot be loaded or the user lacks access, the page shows an error instead of the answers.
