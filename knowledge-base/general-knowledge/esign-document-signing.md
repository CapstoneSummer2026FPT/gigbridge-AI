# E-Sign Document Signing

**Route:** `/contracts/:contractId/documents/:documentId/sign`

**Access:** The authorized signer for the contract document.

The page displays the selected contract document and provides the platform's electronic-signature interaction. The signer reviews the document, supplies the required signature, and submits it for server validation.

A successful submission updates that participant's document status. The user should not assume the overall contract is active until all required signatures and contract conditions are complete.
