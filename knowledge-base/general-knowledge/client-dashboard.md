# Client Dashboard

**Route:** `/client/dashboard`

**Access:** Clients with a completed profile.

The client dashboard summarizes current hiring activity and provides shortcuts into the main client workflows. It shows hiring/job information, financial progress, talent matches, recent activity, and active contracts using current backend data.

Clients can start a job post, review existing work, open talent matching, inspect active contracts, and access AI-assisted job drafting. Empty and loading states are shown when the account has no matching activity or data cannot be loaded.
