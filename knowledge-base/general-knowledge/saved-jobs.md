# Saved Jobs

**Route:** `/jobs/saved`

**Access:** Signed-in users; save and unsave behavior is intended for freelancers.

Saved Jobs collects the project requests a freelancer bookmarked while browsing. A saved item can be opened to review current Job Details or removed from the saved list.

Saving a job does not submit a proposal, reserve the opportunity, or bypass its deadline/status requirements. If there are no saved jobs, the user can return to Browse Jobs to find opportunities.
