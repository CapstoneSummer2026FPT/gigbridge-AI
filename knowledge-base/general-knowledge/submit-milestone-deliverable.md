# Submit Milestone Deliverable

**Route:** `/contracts/:contractId/deliverables/:milestoneId`

**Access:** The freelancer participant for an eligible milestone.

The freelancer uses this page to review the milestone requirements and submit the supported description, links, files, or other evidence of delivery. Required fields and file rules are enforced by the form and backend.

Submitting marks the work for review; it does not itself release escrow. The client must use the milestone review/approval process, or the parties may use revision and dispute mechanisms when necessary.
