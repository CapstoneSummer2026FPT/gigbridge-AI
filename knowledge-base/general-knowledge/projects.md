# Projects

**Route:** `/projects`

**Access:** Clients and freelancers with completed setup.

Projects lists the active or available project workspaces associated with the user's contracts. Each item links the project/job context to its contract and current work status.

Opening a project goes to its Project Workspace. If the user has no eligible projects, the page shows an empty state rather than creating a workspace without a contract.
