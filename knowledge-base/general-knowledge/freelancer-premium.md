# Freelancer Premium Hub

**Route:** `/premium/freelancer`

**Access:** Freelancers with completed setup and active Premium access. Non-Premium freelancers are sent to pricing.

The overview shows the active plan and remaining coverage, automatic-renewal setting, current Elo tier/progress, Vacation Mode status, and profile-promotion status. Users can extend the plan, toggle automatic renewal, or open a specialized Premium tab.

Automatic renewal uses available GigCoin. Turning renewal off does not remove current benefits; access continues through the current end date.
