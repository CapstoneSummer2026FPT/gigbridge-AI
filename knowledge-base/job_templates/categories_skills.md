# IT Job Categories and Skills Taxonomy

This guide defines the standard majors, categories, and skill mappings supported on the GigBridge platform.

## Software Engineering Major (Major ID: 1)
This major covers core programming, design, and architecture domains.

### Web Development Category (Category ID: 101)
*   **Description:** Building frontend, backend, and full-stack web applications.
*   **Key Skills:** JavaScript, TypeScript, React, Vue.js, Node.js, Python, Django, C#, ASP.NET Core, PostgreSQL, MongoDB.

### Mobile Development Category (Category ID: 102)
*   **Description:** Building native and cross-platform mobile apps for iOS and Android.
*   **Key Skills:** Swift, Kotlin, Java, Flutter, Dart, React Native, Objective-C, Mobile UI/UX.

---

## Blockchain & Cryptography Major (Major ID: 2)
This major covers decentralized systems and cryptographic ledgers.

### Smart Contracts Category (Category ID: 201)
*   **Description:** Writing, testing, and auditing smart contracts for decentralized platforms.
*   **Key Skills:** Solidity, Rust, Ethereum, Web3.js, Hardhat, Truffle, Vyper, Cryptography.
